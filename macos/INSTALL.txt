TrustBench 0.5.0 preview

Requirements
Intel Mac running macOS 15.7.9. Other configurations have not been verified.
Live evaluations require Ollama and a downloaded local model.
No separate Python or Git installation is required.

Install
Drag TrustBench.app into Applications, eject the disk image, then launch it.
The preview is ad-hoc signed and is not signed with Apple Developer ID or
notarized. macOS may display a security warning when opening a downloaded copy.
Apple's guidance: https://support.apple.com/102445

Get started
Open Evaluate and select Refresh Models to choose an installed Ollama model.
Use Setup Help for setup instructions, then select a dataset and Start Evaluation.
Reports and Compare work without Ollama. Keyboard Help lists navigation shortcuts;
optional Spoken guidance is off at startup.

Reports
Saved evaluations are stored in:
~/Library/Application Support/TrustBench/reports

Open Evaluation Report can view a file elsewhere. Copy selected older evaluation
JSON files into the folder above to include them in Reports and Compare.
Reports may contain prompts, answers and local paths; review them before sharing.

Update or uninstall
Quit TrustBench before replacing the app in Applications. Back up important
reports before updating. To uninstall, move the app to Trash. The separate report
directory remains until you remove it.

Support
Include app version/build, macOS version, the action attempted and any error.
Source and issues: https://github.com/brian419/trust-bench-python
