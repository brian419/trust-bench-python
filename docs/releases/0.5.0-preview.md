TrustBench is a local AI evaluation tool with Reports, Compare and Evaluate
workflows. This preview packages the desktop app with Python/Tk and example
datasets so users can launch it from Applications without a development checkout.

## Compatibility and requirements

- Preview target: Intel x86_64 Mac running macOS 15.7.9.
- The previous candidate was validated on one Intel MacBook Air. Other hardware,
  older macOS versions and Apple Silicon have not been verified.
- Live evaluation requires separately installed/running Ollama and a downloaded
  model. Reports/Compare work without Ollama.
- This candidate is ad-hoc signed and not notarized. It may be blocked on download;
  it is not represented as Apple-approved or ready for general production use.

## Install

Open the DMG, drag TrustBench.app into Applications, eject the image and launch.
Read INSTALL.txt and the [preview guide](../macos-preview-guide.md) first.
No Python or Git installation is required for the app.

Candidate assets are `TrustBench-0.5.0-macos-x86_64.dmg` and `SHA256SUMS.txt`.
They have not been uploaded. A checksum identifies file integrity; it does not
establish publisher identity. Keep internal build/audit records with the release
evidence and inspect them for local paths before deciding to share them.

## Reports and limitations

Reports live in `~/Library/Application Support/TrustBench/reports` and remain
separate from the app. Old development reports are not migrated automatically.
Back up important reports before replacing an installed candidate.

Evaluation accuracy reflects the configured scorer and chosen examples; it does
not establish general model reliability, factuality, fairness or safety. Missing
model-version/generation metadata can limit comparison reproducibility. Spoken
guidance is optional; complete system screen-reader compatibility is not claimed.

Report issues with app version/build, macOS version, action and exact error.
Review prompts, answers and local paths before attaching reports or logs.
