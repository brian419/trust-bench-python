# TrustBench 0.5.0 preview for Intel macOS

Draft release notes. Build 5003 validation is pending.

TrustBench runs local AI evaluations and provides Reports, Compare and Evaluate
workflows in a native desktop interface. The macOS app includes Python, Tcl/Tk
and example datasets.

## Requirements

- Intel x86_64 Mac running macOS 15.7.9.
- Ollama and a downloaded local model for live evaluation.

Reports and Compare do not require Ollama. Other Mac configurations have not
been verified.

## Installation

Open the DMG, drag TrustBench.app into Applications, eject the image and launch
the app. See the [installation guide](../macos-preview-guide.md).

The preview is ad-hoc signed and is not signed with Apple Developer ID or
notarized. macOS may display a security warning when opening a downloaded copy.

## Included in this preview

- Live evaluation with model discovery, progress and cancellation.
- Saved evaluation reports and compatible report comparisons.
- Keyboard navigation and optional spoken guidance.
- Bundled example datasets and a standalone desktop runtime.

Reports are stored in `~/Library/Application Support/TrustBench/reports` and
remain separate from the app across updates.

## Evaluation limits

Results describe the selected dataset and scorer. Exact-match accuracy is not a
general measure of factuality, fairness, safety or model reliability. Comparison
results depend on the available provenance metadata.
